14-1 JavaScript 弹窗与输出 · document / alert / console / confirm / prompt

方式 1

document.write()

向当前 HTML 文档中直接写入内容。页面加载前调用效果最佳，加载后调用会覆盖整个文档。

// 代码示例 document.write("张艺凡，你好");
方式 2

alert()

弹出一个模态对话框显示消息，必须点击"确定"才能继续浏览。阻塞性强，适合简单提示。

// 代码示例 alert("张艺凡，你好");
方式 3

console.log()

向浏览器开发者工具的控制台输出内容，用户不可见，常用于调试。按 F12 打开控制台查看。

// 代码示例 console.log("张艺凡，你好");
方式 4

confirm()

弹出"确定 / 取消"二选一对话框。点击确定返回 true，点击取消返回 false。常用于危险操作二次确认。

// 代码示例 let ok = confirm("确认吗？"); console.log(ok); // true 或 false

方式 5

prompt()

弹出带输入框的对话框，用户输入后点击确定返回字符串，点击取消返回 null。可传第二个参数作为输入框默认值。

// 代码示例（三种用法） let name = prompt("请输入你的姓名"); // prompt("请输入你的姓名", "默认值"); // prompt("请输入你的姓名", "默认值", "输入框的宽度");
