14-2 JavaScript 六种基础数据类型

JavaScript 有 六种原始数据类型： Number、String、Boolean、Undefined、Null、Symbol。 用 typeof 可以查看一个值的类型（null 是历史 bug，会返回 "object"）。

类型 1

Number · 数字

typeof → "number"

整数、浮点数、科学计数法、特殊值 NaN/Infinity，都是 Number 类型。

let num1 = 42; let num2 = 3.14; let num3 = 1e10; let num4 = NaN; // 非数字 let num5 = Infinity; // 无穷大
类型 2

String · 字符串

typeof → "string"

用单引号、双引号或反引号（模板字符串）括起来的文本内容。

let str1 = "你好"; let str2 = '张艺凡'; let str3 = `今年是 ${2026} 年`; // 模板字符串
类型 3

Boolean · 布尔

typeof → "boolean"

只有两个值：true 和 false，常用于条件判断。

let isOk = true; let isNo = false; let isBig = 10 > 5; // 比较结果也是 Boolean
类型 4

Undefined · 未定义

typeof → "undefined"

变量声明了但没赋值，默认值就是 undefined。

let a; // 只声明没赋值 let b = undefined; // 显式赋值
类型 5

Null · 空值

typeof → "object"（历史 bug）

表示"空"或"无"，需要用 === null 来判断。typeof null 返回 "object" 是 JavaScript 早期遗留的 bug，永远不会修复。

let n = null; // 判断 null 的正确方式： if (n === null) { /* ... */ }
类型 6

Symbol · 符号

typeof → "symbol"

ES6 新增的唯一标识符，每次调用 Symbol() 都会返回一个永不相等的值。常用于对象属性名避免冲突。

let s1 = Symbol(); let s2 = Symbol("myKey"); // 带描述 let s3 = Symbol("myKey"); console.log(s2 === s3); // false，每次都唯一
