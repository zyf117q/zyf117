① push / pop —— 尾部增删

修改原数组 push(...items) 尾部追加元素，返回新长度  |  pop() 尾部弹出最后一个，返回弹出值

const fruits = ["🍎", "🍌"]; fruits.push("🍇"); // → ["🍎","🍌","🍇"] 长度=3 fruits.pop(); // → 弹出 "🍇"，剩余 ["🍎","🍌"]

const q = ["🐱", "🐶", "🐰"]; q.shift(); // → 弹出 "🐱"，剩余 ["🐶","🐰"] q.unshift("🐼"); // → 头部插入 "🐼"

const nums = [1, 2, 3, 4, 5]; const doubled = nums.map(n => n * 2); // → [2, 4, 6, 8, 10] // 原数组不变！

不修改原数组 reduce((acc, cur) => acc + cur, initial) 累加器 + 当前值，算出最终结果

⑦ sort / reverse —— 排序与反转

修改原数组 sort((a,b) => a - b) 数字升序  |  reverse() 反转

const nums = [30,5,100,1,20]; nums.sort((a,b) => a - b); // → [1, 5, 20, 30, 100] 升序 nums.reverse(); // → [100, 30, 20, 5, 1] 反转

⑧ 遍历方法横向对比

遍历 forEach / some / every / find / includes / indexOf —— 一眼看懂它们都在干嘛

const nums = [1,2,3,4,5]; nums.forEach(n => console.log(n)); // 挨个执行，不返回值 nums.some(n => n > 3); // true（有一个 >3） nums.every(n => n > 0); // true（全部 >0） nums.includes(3); // true nums.indexOf(4); // 3（下标） nums.find(n => n > 3); // 4（第一个命中值） nums.findIndex(n => n > 3); // 3（第一个命中下标）
