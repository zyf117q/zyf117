🟦 一、对象（Object）可视化

对象 对象是 key-value（键-值对）的集合，key 永远是字符串，value 可以是任意类型

① 创建 & 访问属性

const user = { name: "张艺凡", age: 20, grade: "大二", isAdmin: false, score: null }; user.name // "张艺凡" 点语法 user["age"] // 20 方括号语法 user["na"+"me"] // "张艺凡" 动态 key

③ Object.keys / values / entries

const book = { title: "JS 红宝书", price: 99, pages: 800 }; Object.keys(book); // ["title", "price", "pages"] Object.values(book); // ["JS 红宝书", 99, 800] Object.entries(book); // [["title","JS 红宝书"], ["price",99], ["pages",800]]
